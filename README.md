# Fake-Logo-Detection

The issue of counterfeit logos has become a significant concern for both brands and consumers alike. These fraudulent logos not only harm brands' reputations but also pose a serious threat to consumers' safety. Additionally, the impact of counterfeit trade on the economy is quite substantial, resulting in revenue losses, legal disputes and customer churn.
Traditional methods for identifying these logos involve manual inspection, which is both time-consuming and prone to errors. With counterfeiters continuously refining their techniques, traditional methods struggle to keep up with the constantly evolving landscape of counterfeit production.
This project is designed to tackle this challenge by applying Deep Learning and Computer Vision techniques to classify logos as genuine or fake. Using a ResNet-18 based model, the system learns robust visual features from logos and performs accurate classification. To enhance interpretability, the project integrates Grad-CAM (Gradient-weighted Class Activation Mapping), which highlights the regions of a logo image that influenced the model’s decision.
This project also incorporates an interactive Streamlit-based user interface, enabling users to upload logos, visualize prediction confidence and even generate comprehensive PDF reports. Additionally, the Training Dashboard provides insights into model performance through accuracy, loss curves and advanced evaluation metrics such as ROC, PR and reliability curves.
